# Modul belajar Tradix

Satu file = satu minggu (`minggu-1.md` … `minggu-8.md`). Situs mengubah tiap file menjadi
halaman `/materi/minggu-N/` dengan animasi "buka buku".

## Aturan menulis

- Bagian atas (frontmatter) berisi `week`, `title`, `subtitle`, `duration`.
- Setiap `## Judul` = **satu halaman buku**. Usahakan 80–140 kata per halaman supaya muat
  di halaman buku desktop.
- Satu kutipan `> ...` per halaman akan dipindah ke halaman kiri sebagai **catatan penting**.
- Diagram di halaman kiri: tulis `<!-- visual: nama-diagram -->`. Daftar nama diagram ada di
  `src/data/diagrams.ts`. Tanpa baris ini, halaman kiri hanya menampilkan catatan.
- Materi adalah bahan edukasi, bukan saran finansial. Jangan menjanjikan profit.
